The first standalone NEON translation source for `bckp/translator-core` 3.x. Requires PHP 8.4+, core `^3.0` and `nette/neon ^3.4`.

- Implements the typed `TranslationSource` contract and returns `MessageCatalogue` entries containing strings or `PluralMessage` objects.
- Discovers `{resource}.{locale}.neon` files only for the requested normalized locale, with deterministic file and directory order.
- Automatic versions hash the file set, paths and contents, detecting additions, removals and edits with unchanged modification times.
- A fixed version string avoids filesystem access during version checks for immutable deployment assets.
- Constructors perform no IO. Invalid data and unreadable paths produce explicit exceptions.
- The source works with the core's bundled PHP storage, `MemoryStorage`, and the Nette adapter 3.0.

See the [usage and file-format manual](https://github.com/bckp/translator-neon/blob/v1.0.0/README.md).

Validation: PHP 8.4 and 8.5 tests, PHPStan 8, PER3 with tabs, Composer audit, API compatibility tooling, and a clean Nette production installation using the source.
